# PAL Mobile 2.0.1

## What changed

- New Chat, Activity and Pinned Replies stop bouncing when you reach the end. You can scroll back immediately or drag the handle to dismiss the sheet.
- Forms keep their reading position when opening the keyboard changes the layout. Pairing keeps the verification action within reach.
- Send, Stop and Retry share one position in the composer. While a reply streams, you can read earlier messages and use Latest to return.

## Compatibility

PAL Mobile requires Android 11 or later. An in-place update signed with the same key preserves pairing and encrypted app data. Older compatible desktops continue to advertise the controls they support.
