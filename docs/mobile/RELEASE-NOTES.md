# PAL Mobile 2.0.0

[Download the Android APK](https://github.com/otectus/PAL/releases/download/mobile-dev-v2.0.0/pal-mobile-v2.0.0-dev.apk) for Android 11 or later. If you use Cere Mobile 0.1.5, download it directly and choose **Update** to keep your pairing, conversations and drafts. The older app can miss the update after the repository rename. Update your computer to PAL Desktop 2.0.0 for the matching broker.

## What changed

- **App identity.** The number under **PAL** in the top-left corner shows the installed app version, including when the paired computer has an older name. The new launcher and notification icons use PAL’s cyan-eyed robot face.
- **Conversations.** Read selectable Markdown, copy code blocks and return to the latest reply after scrolling back. Send and Stop share a consistent position beside the multiline composer. Interrupted replies and sends awaiting confirmation have distinct states.
- **Pairing and approvals.** Connection status explains when PAL is reconnecting or needs your attention. Approval requests show the action and its target before you decide. Light and dark themes support larger text throughout these flows.
- **Research in Work.** Full-access owners can choose web or project sources, edit the plan, set limits and start research on the paired desktop. Inspect the passages behind a finding, pause or steer the run, and export the report as Markdown, CSV, BibTeX, or JSON.
- **Activity Log.** Expand a conversation’s activity cards to inspect and copy an event. Request the full output when the initial preview is truncated, or load older events from the desktop.

## Compatibility

This GitHub prerelease uses the existing development package `dev.otectus.cere.mobile.debug`, version code `2000000`. The release includes checksums, the signing certificate fingerprint and the same APK under the former Cere filename. Research requires a full-access owner connection and a supported saved conversation on the paired desktop. Older compatible desktops continue to advertise the controls they support.
